# List и Dict в Python

## 1. List (Список)

`list` — это тип данных в Python, который позволяет хранить несколько элементов в одной переменной.

### Особенности List:
- Хранит несколько элементов.
- Элементы имеют определённый порядок.
- Каждый элемент имеет свой индекс (начиная с 0).
- Допускает повторяющиеся значения.
- Список можно изменять после создания.
- Может содержать разные типы данных.

### Создание списка

```python
fruits = ["apple", "banana", "orange"]
numbers = [1, 2, 3, 4, 5]
mixed = ["hello", 10, True, 3.14]
```

### Получение элементов

Для получения элемента используется индекс.

```python
fruits = ["apple", "banana", "orange"]

print(fruits[0])  # apple
print(fruits[1])  # banana
print(fruits[2])  # orange
```

Отрицательные индексы позволяют обращаться к элементам с конца списка.

```python
print(fruits[-1])  # orange
print(fruits[-2])  # banana
```

### Основные методы List

| Метод | Описание |
|---|---|
| `append(x)` | Добавляет элемент в конец списка |
| `insert(i, x)` | Добавляет элемент по указанному индексу |
| `remove(x)` | Удаляет первый найденный элемент |
| `pop(i)` | Удаляет и возвращает элемент по индексу |
| `sort()` | Сортирует список |
| `reverse()` | Переворачивает список |
| `clear()` | Удаляет все элементы |
| `count(x)` | Считает количество элементов со значением x |
| `index(x)` | Возвращает индекс элемента |
| `copy()` | Создаёт поверхностную копию списка |

### Примеры использования

```python
numbers = [1, 2, 3]

numbers.append(4)
print(numbers)  # [1, 2, 3, 4]

numbers.insert(0, 10)
print(numbers)  # [10, 1, 2, 3, 4]

numbers.remove(2)
print(numbers)  # [10, 1, 3, 4]

numbers.pop()
print(numbers)  # [10, 1, 3]

numbers.sort()
print(numbers)  # [1, 3, 10]
```

### Перебор списка через цикл

```python
fruits = ["apple", "banana", "orange"]

for fruit in fruits:
    print(fruit)
```

### Срезы (Slicing)

Срезы позволяют получить часть списка.

```python
numbers = [1, 2, 3, 4, 5]

print(numbers[1:3])  # [2, 3]
print(numbers[:3])   # [1, 2, 3]
print(numbers[2:])   # [3, 4, 5]
print(numbers[::-1]) # [5, 4, 3, 2, 1]
```

## 2. Dict (Словарь)

`dict` — это тип данных в Python, который хранит информацию в формате **ключ: значение** (`key: value`).

Каждое значение доступно через свой ключ.

### Особенности Dict:
- Хранит данные в формате ключ: значение.
- Ключи должны быть уникальными.
- Значения могут повторяться.
- Можно изменять, добавлять и удалять элементы.
- Сохраняет порядок добавления элементов.
- В качестве ключей используются неизменяемые хешируемые объекты, например строки, числа и кортежи.

### Создание словаря

```python
person = {
    "name": "Alex",
    "age": 20,
    "city": "Almaty"
}
```

В этом примере:
- `"name"` — ключ.
- `"Alex"` — значение.
- `"age"` — ключ.
- `20` — значение.

### Получение значений

Для получения значения используется ключ.

```python
person = {
    "name": "Alex",
    "age": 20
}

print(person["name"])  # Alex
print(person["age"])   # 20
```

Также можно использовать метод `get()`.

```python
print(person.get("name"))  # Alex
print(person.get("email")) # None
```

`get()` возвращает `None`, если ключ не найден, если не указано другое значение по умолчанию.

### Добавление и изменение элементов

```python
person = {
    "name": "Alex",
    "age": 20
}

# Добавление нового элемента
person["city"] = "Almaty"

# Изменение существующего элемента
person["age"] = 21

print(person)
```

Результат:

```python
{
    "name": "Alex",
    "age": 21,
    "city": "Almaty"
}
```

### Удаление элементов

```python
person = {
    "name": "Alex",
    "age": 20,
    "city": "Almaty"
}

person.pop("age")  # Удаляет элемент по ключу

del person["city"] # Удаляет элемент по ключу

print(person)
```

### Основные методы Dict

| Метод | Описание |
|---|---|
| `get(key)` | Получает значение по ключу |
| `keys()` | Возвращает все ключи |
| `values()` | Возвращает все значения |
| `items()` | Возвращает пары ключ: значение |
| `update()` | Обновляет словарь |
| `pop(key)` | Удаляет элемент по ключу и возвращает его значение |
| `clear()` | Удаляет все элементы |
| `copy()` | Создаёт поверхностную копию словаря |
| `setdefault()` | Возвращает значение ключа или добавляет его со значением по умолчанию |

### Перебор словаря через цикл

**Перебор ключей:**

```python
person = {
    "name": "Alex",
    "age": 20
}

for key in person:
    print(key)
```

**Перебор значений:**

```python
for value in person.values():
    print(value)
```

**Перебор ключей и значений:**

```python
for key, value in person.items():
    print(key, value)
```

## 3. Разница между List и Dict

| Характеристика | List | Dict |
|---|---|---|
| Хранение данных | Элементы | Ключ: значение |
| Обращение к данным | По индексу | По ключу |
| Порядок | Сохраняется | Сохраняется порядок добавления |
| Повторения | Разрешены | Ключи уникальны |
| Изменяемость | Да | Да |
| Синтаксис | `[]` | `{}` |

### Пример сравнения

**List:**

```python
student = ["Alex", 20, "Almaty"]

print(student[0])  # Alex
print(student[1])  # 20
```

**Dict:**

```python
student = {
    "name": "Alex",
    "age": 20,
    "city": "Almaty"
}

print(student["name"])  # Alex
print(student["age"])   # 20
```

Главное отличие: в `list` элементы находятся на определённых позициях, а в `dict` значения хранятся под определёнными ключами.

## 4. Вложенные List и Dict

В Python можно создавать списки внутри словарей, словари внутри списков и другие комбинации.

### List внутри Dict

```python
student = {
    "name": "Alex",
    "grades": [5, 4, 5, 3]
}

print(student["grades"][0])  # 5
```

### Dict внутри List

```python
students = [
    {"name": "Alex", "age": 20},
    {"name": "Anna", "age": 19},
    {"name": "John", "age": 21}
]

print(students[0]["name"])  # Alex
print(students[1]["age"])   # 19
```

## 5. Когда использовать List и Dict?

**Используй List, когда:**
- Нужно хранить последовательность элементов.
- Важен порядок элементов.
- Нужно обращаться к элементам по индексам.
- Необходимо хранить повторяющиеся значения.

**Используй Dict, когда:**
- Нужно хранить данные в формате ключ: значение.
- Необходимо быстро находить информацию по ключу.
- Нужно описать объект с разными характеристиками.
- Необходимо связать одни данные с другими.

## 6. Итог

- `list` — список элементов, к которым можно обращаться по индексам.
- `dict` — словарь, в котором данные хранятся в формате ключ: значение.
- Оба типа данных изменяемые.
- `list` создаётся с помощью `[]`.
- `dict` создаётся с помощью `{}`.
- Оба типа данных часто используются вместе.

**Запомни:**

```python
# LIST
numbers = [10, 20, 30]
print(numbers[0])  # 10

# DICT
person = {"name": "Alex", "age": 20}
print(person["name"])  # Alex
```
